Linux Filesystem Basics

Linux uses a hierarchical filesystem. At the top of the hierarchy is the
root directory, represented by a forward slash (/). All files and
directories are located somewhere under the root directory.

1. Root Directory (/)

The root directory is the top-level directory of a Linux filesystem.

Example:

/

All other directories, such as /home, /etc, and /var, are located under the
root directory.


2. /home

The /home directory normally contains the personal directories of regular
users.

Example:

/home/alice
/home/bob

A user's personal files, such as documents and downloads, are commonly
stored inside their home directory.


3. /etc

The /etc directory contains system-wide configuration files.

Examples include configuration files for installed services and other
system components.

System administrators commonly modify configuration files under /etc when
configuring Linux systems.


4. /var

The /var directory contains variable data that changes while the system is
running.

Examples include log files, cached data, and other files generated by
system services.

A common directory is:

/var/log

which contains system and application logs.


5. /tmp

The /tmp directory is used for temporary files created by applications and
users.

Files stored in /tmp are generally considered temporary and may be removed
by the system.


6. /usr

The /usr directory contains many user-space programs, libraries, and
documentation.

Common subdirectories include:

/usr/bin
/usr/lib
/usr/share

Many commands available to users are located under /usr/bin.


7. /bin

The /bin directory traditionally contains essential command-line programs
needed for basic system operation.

On many modern Linux distributions, /bin may be a symbolic link to another
directory such as /usr/bin.


8. Absolute Paths

An absolute path specifies the complete location of a file or directory
starting from the root directory.

Example:

/home/alice/documents/notes.txt

This path identifies the location independently of the user's current
working directory.


9. Relative Paths

A relative path specifies a location relative to the user's current
working directory.

For example, if the current directory is:

/home/alice

then:

documents/notes.txt

refers to:

/home/alice/documents/notes.txt


10. . and ..

The special directory name "." refers to the current directory.

The special directory name ".." refers to the parent directory.

Example:

cd ..

This moves to the parent directory of the current working directory.


11. File and Directory Navigation

The cd command is used to change the current working directory.

Example:

cd /home/alice

The pwd command displays the current working directory.

The ls command lists files and directories in the current directory.

Together, these commands are commonly used to navigate the Linux
filesystem.
